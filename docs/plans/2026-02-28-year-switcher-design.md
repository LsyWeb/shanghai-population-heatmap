# Year Switcher Design

**Date:** 2026-02-28
**Topic:** 添加 2025 年数据及年份切换功能
**Status:** Approved

## Overview

在现有单文件可视化页面中添加 2025 年各区人口数据，并在右侧面板新增年份切换控件（2024 / 2025），实现跨年数据对比。

## 数据来源

- **2024 年数据**：现有数据，来自 2024 年上海统计年鉴
- **2025 年数据**：来自各区 2024 年国民经济和社会发展统计公报（xzqh.org 整合，部分经官方网站核实）

## 数据结构变更

新增 `yearData` 常量，以年份 → 区ID → 人口值索引：

```js
const yearData = {
  '2024': { pudong: 568.2, minhang: 272.5, ... },
  '2025': { pudong: 578.58, minhang: 272.50, ... }
};
```

新增辅助函数，所有 `d.pop` 直接访问改为：

```js
function getPop(d) {
  return yearData[currentYear][d.id];
}
```

`area`（面积）数据不变，无需按年份区分。

## UI 变更

右侧面板在「显示模式」上方新增「年份」切换组，复用 `.toggle-btn` / `.view-toggle` 样式：

```
┌───────────────────┐
│ YEAR              │
│ [ 2024 ] [ 2025 ] │  ← 新增
│                   │
│ 显示模式           │
│ [常住人口][人口密度] │
│                   │
│ 图例 ...           │
└───────────────────┘
```

Header 副标题年份标识（`· 2024`）和右上角数据来源角标随切换动态更新。

## 函数/状态变更

| 项目 | 变更说明 |
|------|---------|
| `currentYear` | 新增状态变量，初始值 `'2024'` |
| `getPop(d)` | 新增辅助函数，返回 `yearData[currentYear][d.id]` |
| `getDensities()` | 改用 `getPop(d)` 替代 `d.pop` |
| `getNormalized(mode)` | 改用 `getPop(d)` |
| `renderMap(mode)` | 改用 `getPop(d)`，Tooltip 中改用 `getPop(d)` |
| `renderList(mode)` | 改用 `getPop(d)` |
| `showTooltip(...)` | 改用 `getPop(d)` |
| `setYear(year)` | 新增函数：更新 `currentYear`、激活对应按钮、更新 Header 文本、调用 `renderMap` + `renderList` |
| 右侧统计数字 | 改为从数据动态计算（总人口 = 所有区 `getPop` 之和；平均密度 = 总人口 / 总面积），不再硬编码 |

## 成功标准

- 切换年份后地图颜色、列表排名、Tooltip、统计数字、Header 标注全部更新
- 2024 / 2025 两个年份数据均正确展示
- 年份切换与显示模式（人口 / 密度）切换正交独立，任意组合均正常工作
